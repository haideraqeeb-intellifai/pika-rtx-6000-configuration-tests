The original preparation pass is in prepare.py; the benchmark runner is experiment.py. Replace names with unused directories on rerun, and gate the GPU before every block.

export PYTHONPATH="$PWD/agent/rtx6000_benchmark/fast_dependencies/site-packages:$PWD"

Decision context and limits

Surya huddle sets a rough 20% latency reduction bar: B ≤ 0.8 × A, equivalent to at least 1.25× throughput at equal workload. The earlier 1T+2V result was 208.868 seconds plus a separately timed ~0.060-second timestamp correction; it is historical reference, not one of these matched measurements. Initial model weights load lazily during the first warmup, so the startup figures isolate process setup while warmup figures include cold model loading and all generation; a pure model-loading subphase is not separately timed. Visual review remains useful for motion and lip sync.
