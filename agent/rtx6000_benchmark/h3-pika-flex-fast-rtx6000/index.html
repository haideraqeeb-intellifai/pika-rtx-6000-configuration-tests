What changed?

Step 1 uses SageAttention2; step 2 uses SageAttention3 FP4. Selected video-VAE decoder projections use NVFP4, retaining a CPU cache of quantized weights in each VAE worker. The input, seeds, chunk lengths, number of steps, export settings and model-copy counts stay fixed.

Reproduce and audit

Complete timings, counters and quality checks · Timing CSV · Code, inputs, provenance and logs

The source archive records the exact repository commit, source hashes and package versions. SageAttention3 was built from d1a57a5 with CUTLASS 0b55a2f using CUDA 13.1 against PyTorch 2.11.0+cu130, in a private dependency overlay. Existing packages were retained. Calibration tested repeated stage calls. Every fast chunk must use SA2 and SA3 without fallback; every VAE chunk must execute NVFP4 GEMMs.

The harness refreshes request-local sampler/attention nodes while retaining model loaders. A small runtime validation adjustment permits decode-only fast graphs and verifies their NVFP4 calls. No deployment or merge was performed. GPU ownership was monitored; contended runs are excluded.
